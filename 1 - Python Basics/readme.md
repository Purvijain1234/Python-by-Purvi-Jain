## ✅ Summary

| Topic | Key Takeaway |
|-------|--------------|
| Variables & types | Python is dynamically typed; use `type()` to inspect |
| Type casting | `int()`, `float()`, `str()`, `bool()` — `int()` truncates, doesn't round |
| Input / Output | `input()` always returns a string; cast it when you need a number |
| Operators | `/` → float, `//` → floor division, `%` → remainder, `**` → power |
| String methods | Strings are immutable; methods return new strings |
| f-strings | `f"{value:.2f}"` for formatting; `f"{var=}"` for quick debugging |
| Comments & style | Follow PEP 8; docstrings document intent; comments explain *why* |
