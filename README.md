## 🚀 How to Use This Repo

1. **Clone the repository**
```bash
git clone https://github.com/Purvijain1234/Python-by-Purvi-Jain.git
```

2. **Navigate to any section**
```bash
cd 01_Python_Basics
```

3. **Run any file**
```bash
python filename.py
```

> 💡 No external libraries needed for most sections. Just Python 3.x installed on your system.
